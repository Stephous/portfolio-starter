## Workflow de Déploiement

```
1. Développement local
   src/app/* → npm run start (ng serve)
   
2. Build pour production
   npm run build:vercel
   ↓
   dist/portfolio/browser/ ← Contenu déployé
   
3. Push sur Git
   git push origin main
   
4. Vercel détecte & rebuild
   - npm install
   - npm run build
   - Déploie vers Edge Network
   
5. Site accessible mondialement
   https://ton-site.vercel.app
```

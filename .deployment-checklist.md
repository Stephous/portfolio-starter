## Déploiement sur Vercel

### Option A: Via Interface Web (Recommandé)

1. **Connexion GitHub**
   - Va sur [vercel.com](https://vercel.com)
   - Clique "Sign Up with GitHub"
   - Autorise Vercel à lire tes repos

2. **Import du Projet**
   - Clique "Add New..." → "Project"
   - Recherche `portfolio-starter` dans ta liste GitHub
   - Vercel détecte automatiquement :
     - Framework: Angular
     - Build Command: `npm run build`
     - Output Directory: `dist/portfolio`

3. **Déploiement**
   - Vérifie les paramètres (déjà corrects par défaut)
   - Clique "Deploy"
   - Attends 2-5 minutes (build + déploiement)
   - Ton site est en ligne ! 🎉

4. **URL de ton site**
   ```
   https://portfolio-starter-git-main-thyteam.vercel.app
   # ou après ajout domaine :
   https://portfolio.stephane.fr
   ```

### Option B: Déploiement Automatique via CLI

```bash
# Installation Vercel CLI
npm install -g vercel

# Connexion
vercel login

# Déploiement
vercel --prod
```

## Après le Déploiement

### 1. Vérifications à faire

- [ ] Site accessible sans mot de passe
- [ ] Toutes les pages visibles (accueil, projets, contact...)
- [ ] Navigation fonctionne (pas de erreurs 404)
- [ ] Images chargées (test avec console F12)
- [ ] Formulaires fonctionnels (si applicable)
- [ ] Responsive design OK sur mobile

### 2. Configuration Domaine Personnalisé

Si tu veux utiliser ton propre nom de domaine :

1. **Dans Vercel Dashboard :**
   - Project Settings → Domains
   - Ajoute ton domaine (ex: `portfolio.stephane.fr`)
   - Vercel vérifie automatiquement les DNS

2. **Configure les DNS chez ton registrar :**
   
   Pour un domaine complet (`example.com`) :
   ```
   Type: CNAME
   Name: @
   Value: [automatiquement par Vercel]
   
   Type: A Record
   Name: @
   Value: 76.76.21.21 (ou 172.64.155.% - IP dynamique)
   ```

   Pour un sous-domaine (`www.example.com`) :
   ```
   Type: CNAME
   Name: www
   Value: [automatiquement par Vercel]
   ```

3. **Propagation DNS :** 15min à 2h selon ton registrar

## Maintenance

### À chaque modification du site :
```bash
git add .
git commit -m "Update portfolio"
git push origin main
# Vercel rebuild automatiquement !
```

### Build échoue ?
1. Vérifie console pour erreurs de build
2. Nettoie cache npm : `rm -rf node_modules && npm install`
3. Refais le push sur GitHub
4. Vercel retry automatiquement

### Logs en temps réel :
```bash
vercel logs [deployment-url]
```

## FAQ

### Q: Mon site est-il public ?
**A:** Oui, sur Vercel c'est public par défaut. Pour rendre privé :
- Project Settings → Private Projects
- Active "Private" (payant au-delà du gratuit)

### Q: Puis-je déployer sans GitHub ?
**A:** Non, Vercel nécessite un repo Git. Tu peux utiliser GitLab ou Bitbucket aussi.

### Q: Combien de trafic gratuit ?
**A:** ~100GB/mois (suffisant pour presque tous les portfolios)

### Q: Les formulaires fonctionnent-ils ?
**A:** Pas nativement. Pour les formulaires :
- Utilisation services tiers (Formspree, EmailJS)
- Ou backend personnalisé
- Configuration dans `.vercel/functions/` si nécessaire

### Q: Puis-je utiliser ma propre API ?
**A:** Oui, configure l'URL de ton API dans :
- Vercel Environment Variables
- Ou fichier client-side approprié

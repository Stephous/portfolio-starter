📋 Étapes pour Déployer

Option 1 : Via l'interface Web (Plus simple)

  1. Vais sur vercel.com
  2. Clique sur Add New... → Project
  3. Importe ton GitHub repo portfolio-starter
  4. Vercel détecte Angular automatiquement ✨
  5. Ajoute un domaine personnalisé (optionnel)
  6. Clique sur "Deploy"
  7. Ton site est en ligne en 2-5 minutes ! 🎉

Option 2 : Déploiement Automatique via Git

npm install -g vercel vercel login vercel --prod

A chaque push sur GitHub, Vercel rebuild automatiquement ! 🔄

🌐 Domaine Personnalisé

Ajoute ton propre nom de domaine (ex: portfolio.stephane.fr) :

  1. Vais dans Project Settings → Domains
  2. Tape ton domaine
  3. Ajoute les DNS correspondants chez ton registrar

🔧 Commandes Utiles

Test le build local :

npm run build:vercel

Voir les logs en production :

vercel logs
